# Guess-The-Number

A fun and interactive Python number guessing game where players try to guess a randomly generated number between 1 and 100 within limited attempts. The game includes a colorful visual grid interface using the Colorama library.

# Features
🎯 Random number generation
🎨 Colored visual feedback system
🔼 Too high / too low hints
🔢 Limited attempts gameplay
🖥️ Console-based interactive interface
